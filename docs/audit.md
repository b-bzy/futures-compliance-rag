## 一、P0 —— 影响可信度，给人看之前必须修

### 1.1 14/190 份文档的标题回退成了 doc_id ⚠️ 最严重

**证据**：

```
sse_rulebook_catalog_vol1 | szse_sz100etf_contract | szse_guide_marketmaker
shfe_option_admin | shfe_cu_option_guide | dce_soybean_meal_option ...（共 14 份）
```

全是 `sources.yaml` 里 `kind: doc` 的 PDF 直链条目 —— 它们没有 HTML `<title>`，
而 `title_from_notes()` 只在 notes 以 `title=` 开头时生效（那是 adapter 的产物），
所以直接回退成了 `rec["id"]`。

**三处连锁污染**：

1. **用户看到的引用**变成 `szse_sz100etf_contract` 而不是「深证100ETF期权合约基本条款」
2. **条款表父块的主语**取自 `doc.title`，于是正文变成
   `dce_soybean_meal_design的到期日：同最后交易日`
3. **困难评测集里混进了这些坏问题**：
   `dce_soybean_meal_design合约的到期日是如何规定的？`
   —— 主表 150 条里有一部分是这种，虽然不影响相对比较（各档位面对同样的题），
   但作为作品集展示很难看

**修法**：`sources.yaml` 每个 `kind: doc` 条目补一个 `title:` 字段（14 处，手写一次），
`crawl` 时写进 manifest 的 notes，解析时优先读。兜底再加 PDF 元数据 `/Title`
与首页首行标题识别。

**工作量**：约 1 小时。**修完必须重跑 02→03→04，约 40 分钟。**

### 2.2 文号抽取率 26%（50/190）—— 已复核，主要是语料属性，不是抽取缺陷

> **本条已于 2026-09-10 复核并改写。** 原文断言「`extract_doc_no` 只认一种全角
> 样式，实际还有 `第 48 号`、英文 `Circular No. 12` 等变体」，并在执行计划里
> 承诺「文号覆盖率 26%→80%+」。**这两条都被实测推翻**，下面是证据。

**测得的事实**（全部对 190 份文档的全文、以及 `data/raw` 下的原始文件实跑）：

| 检验 | 结果 |
|---|---|
| 原文声称的变体 `第 N 号` / `N 年第 N 号` / 英文 `Circular No.` | 语料中命中 **0 份** |
| 无机构前缀的 `〔2026〕68号` | **1 份**（郑商所期权交易管理办法） |
| 把扫描窗口从 3000 字符放大到全文 | 49 → **50** 份，仅 +1 |
| 全文都不含文号的文档 | **140 份**（CFFEX 99 · SSE 24 · 其余 17） |
| 这 140 份中前 3000 字符连「号」字都没有的 | **122 份** |
| CFFEX「通知」类但抽不到文号的 25 份，其**原始 HTML** 里有文号的 | **0/25** |

最后一行是关键：不是解析丢失，是中金所那些页面本身不印发文字号。

**为什么 74% 抽不到**：缺文号的文档是合约条款表（`易方达科创50ETF期权合约基本条款`）、
常设规则手册（《中国金融期货交易所交易规则》《结算规则》）、投资者问答，
以及 SGX / HKEX / OCC / SEC 的英文 rulebook。这些**本身就不带发文字号** ——
文号只出现在发布它们的那份通知里。对这类文档返回 `None` 是正确行为，不是漏检。
对照组也印证了这一点：CFFEX 抽到文号的 14 份，全部是「关于……的通知」。

**已做的修复**：机构前缀改为可选、并允许前缀与括号间有空白
（`clean.py` `_DOC_NO`）。**收益就是 49 → 50，如实记录。**
没有添加 `第 N 号` / 英文变体的分支 —— 0 命中的代码分支正是本文 §1.2
批判的「装饰品」。新增 11 个单元测试，含负例（合约条款表必须返回 `None`）
与防御用例（带空格时不得丢掉机构简称）。

**真实天花板**：即使把上交所《制度规则汇编》两卷 PDF（已抓到，含序号/文号/
标题/发布时间/效力层级）建成权威对照表按标题反查回填，能覆盖的也只是缺文号
文档里的 SSE 那 24 份 → **50 + 24 = 74/190 ≈ 39%**。CFFEX 那 99 份没有任何
可用数据源。**原先写的 80%+ 不可达。**
