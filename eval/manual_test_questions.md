# 人工测试问题清单

给人用的，不是给脚本跑的。所有「预期答案」都从 `data/processed/parents.jsonl` 里逐条核对过，
可用 `grep` 复查；标注「应拒答」的题目已确认语料中确实没有对应内容。

**怎么用**

```bash
streamlit run src/derivrag/ui/app.py     # 界面测
# 或
curl -s localhost:8000/query -H 'Content-Type: application/json' \
  -d '{"question":"上证50ETF期权的合约单位是多少？"}' | jq
```

**每题按 4 个维度打勾**，任一不过就算这题没过：

| 维度 | 判定 |
|---|---|
| 检索命中 | top-5 里有正确来源文档 |
| 答案正确 | 数值/结论与预期一致 |
| 引用准确 | 引用的条号/文号确实是该答案的出处，不是别的条 |
| 无幻觉 | 没有编造语料里不存在的数字、条号、机构 |

建议顺序：先跑 A、B 两组（基本盘，全对才有意义），再跑 G、H、J 三组（这三组最能暴露问题）。

## F. 多跳 / 需要合成多个块（期望 4/5）

| # | 问题 | 预期答案 |
|---|---|---|
| F1 | 指数熔断对股票期权市场有哪些影响？ | 至少覆盖：①期权市场同步暂停/恢复交易 ②熔断期间不揭示虚拟参考价格、虚拟匹配量、虚拟未匹配量 ③恢复交易方式按是否 14:57 前结束分情形 ④行权日/交收日的特殊处理（需合成 5+ 个问答块） |
| F2 | 行权日发生指数熔断并持续到收盘，怎么处理？ | 当日不再恢复交易；最后交易日顺延至恢复交易首日；当日已接受的行权申报按无效处理，可在恢复交易首日重新申报 |
| F3 | 交收日发生指数熔断并持续到收盘，行权交割怎么做？ | 有券交券、没券部分现金结算；ETF 行权现金结算价 = 前一交易日单位净值 ×（1 + 对应指数当日涨跌幅） |
| F4 | 结算参与人结算准备金余额小于零，会发生什么？谁来执行强平？ | 未能在规定时间补足或自行平仓的，由**中国结算**实施强行平仓，**委托上交所执行**（第一百三十八条） |
| F5 | 期权自身的熔断机制和指数熔断有什么区别？ | 触发源不同：期权熔断由自身价格波动触发，指数熔断与证券市场联动 |

> **F5 是这份清单里唯一的「语料内部冲突」题**，价值最高：
> 《指数熔断机制问答》说触发条件是「涨跌达到或超过 50% **且价格涨跌绝对值达到或超过最小报价单位的 5 倍**」，
> 而各 ETF 期权《合约基本条款》的「熔断机制」写的是「**10 个最小报价单位**」。
> 两个数都在库里。**理想表现是给出其中一个并标明出处；说得笃定又不给出处，就是这题真正的失败。**

## K. 多轮对话（考查询改写，期望 2/2 组全程不掉链子）

**K1**
1. 沪深300股指期权的行权方式是什么？ → 欧式
2. 那最后交易日呢？ → 到期月份第三个星期五（考"那…呢"能否补全主语）
3. 和上交所50ETF期权比呢？ → 需要切换主体到 SSE，答第四个星期三

**K2**
1. 豆粕期权是美式还是欧式？ → 美式
2. 行权申请最晚什么时候提？ → 到期日 15:30 之前
3. 它的最小变动价位是多少？ → 0.5 元/吨（考第三轮"它"还指不指豆粕，不能漂移到股指期权）

> 常见失败模式是第 3 轮主体漂移。K1 第 3 轮要求主动换交易所，K2 第 3 轮要求主体保持不变，两种方向都测到了。
